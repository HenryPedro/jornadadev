# ⚠️ Aviso de Contingência: Dicionário de Dados

Conforme autorizado pelas regras de avaliação do TCC e pelas instruções, esta pasta não contém os arquivos físicos `.DBF` ou `.CSV` gerados pelo utilitário de exportação.

Por favor, retorne à raiz do projeto para consultar a arquitetura de dados estruturada.
